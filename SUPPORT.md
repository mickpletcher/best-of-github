# Support

Best of GitHub curates links and publishes automated rankings. Inclusion is not an endorsement, security review, or accessibility certification of a third-party project.

## Choose the right route

- **Suggest a repository:** use the [repository suggestion form](https://github.com/mickpletcher/best-of-github/issues/new?template=repository-suggestion.yml) and follow [CONTRIBUTING.md](CONTRIBUTING.md). New candidates normally enter Mick's Watchlist first. Disclose affiliations and commercial interests.
- **Correct a catalog or report entry:** use the [stale or incorrect metadata form](https://github.com/mickpletcher/best-of-github/issues/new?template=stale-metadata.yml).
- **Report a maintenance-script or documentation problem:** use the [bug report form](https://github.com/mickpletcher/best-of-github/issues/new?template=bug_report.yml). Include a sanitized command, error, and affected file when relevant.
- **Report an accessibility barrier or request an alternative:** follow [ACCESSIBILITY.md](ACCESSIBILITY.md).
- **Ask a general question:** search existing issues, then open a [blank issue](https://github.com/mickpletcher/best-of-github/issues/new). The forms are optional if they prevent you from reporting a problem.
- **Report a vulnerability in this repository:** follow [SECURITY.md](SECURITY.md) rather than posting details publicly.
- **Report a conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md); do not post incident details in a public issue.

For installation, usage, bugs, or vulnerabilities in a listed project, use that project's own documentation and reporting channels. This repository cannot provide support or make commitments for those projects.

Public issues should not contain credentials, personal information, or private logs. Support is provided as time permits; there is no guaranteed response time for general requests.
