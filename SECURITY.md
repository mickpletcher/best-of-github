# Security Policy

## Supported Version

This repository publishes generated Markdown reports and maintenance automation rather than versioned software packages. Security fixes are applied to the latest state of the `main` branch.

## Report a Vulnerability

Use the repository's **Security** tab and **Report a vulnerability** option to submit a private report. Do not open a public issue for suspected token exposure, workflow injection, unsafe automation, or another vulnerability that could put users or repositories at risk.

Include:

- the affected file, workflow, or generated content;
- clear reproduction steps or a proof of concept;
- the likely impact;
- any suggested mitigation; and
- whether the issue is already public.

You should receive an acknowledgment within seven days. Confirmed issues will be prioritized by impact, and disclosure will be coordinated after a fix is available.

Stale links, inaccurate descriptions, category disagreements, and ordinary repository suggestions are not security issues; use the appropriate issue form for those.
