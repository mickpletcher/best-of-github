# Mick's Watchlist

Repos here are worth monitoring, but they are not ready for the main curated README list yet.

Use this file for projects that look useful, fast moving, experimental, duplicated by another listed repo, or not yet tested enough to recommend.

## Promotion Criteria

- Clear fit for Mick's AI, automation, endpoint, document, web automation, media, or security workflows.
- Strong reason to keep it beyond star count alone.
- Active enough to trust or stable enough to archive as a reference.
- Tested locally, used in a real workflow, or reviewed deeply enough to explain the practical value.
